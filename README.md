# 🤖 Automated Customer Support Data Cleaning Tool

## 📌 Project Overview
An Excel-based automated data cleaning tool built with VBA Macros and 
SQL queries to clean, standardize, and analyze messy customer support 
ticket data — reducing manual effort and improving data accuracy.

## 📁 File Structure (6 Sheets)
| Sheet | Description |
|-------|-------------|
| Raw Data (Messy) | Original unclean data — duplicates, mixed formats, missing values |
| Clean Data (After Macro) | Output after VBA Macro execution |
| VBA Macro Code | Full automation code — CleanCustomerSupportData() |
| Cleaning Log | Auto-generated log of all cleaning steps |
| SQL Queries | 7 analysis queries — STATUS, CSAT, Resolution Time, Escalation |
| Summary Report | KPI cards + live formula-based breakdown |

## 🛠️ Tools & Skills Used
- **VBA Macros** — Duplicate removal, Proper Case, Date standardization, Missing value flagging
- **SQL** — GROUP BY, HAVING, AVG, COUNT, SUBSTR, WHERE, IN operator
- **Excel** — COUNTIF, AVERAGEIF, COUNTA, Conditional Formatting

## 🔍 Key Features
- One-click macro cleans entire dataset automatically
- Detects duplicates via email matching (case-insensitive)
- Standardizes date formats to YYYY-MM-DD
- Flags missing values with ⚠ warning
- 7 SQL queries for complete data analysis
